Airfoil → SolidWorks XYZ

Paste a Selig-format airfoil .dat file, preview it, and export a space-separated XYZ .txt file for Insert → Curve → Curve Through XYZ Points. Runs locally in your browser.

1 · Airfoil coordinates

Selig format: optional airfoil name, then X Y coordinate pairs around the perimeter.

2 · Geometry options

Recommendation: leave AoA at 0° here, then set the freestream direction in Fluent for angle sweeps. Positive AoA here rotates the airfoil counterclockwise, nose up.

Paste coordinates and click Update preview.

Output: exactly three space-separated columns (X Y Z), Z = 0, with meter suffixes, no tabs or header. The file uses the same delimiter and unit style as your working A18 file.
